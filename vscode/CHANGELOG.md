# Changelog

All notable changes to this project will be documented in this file.

## [0.2.0] - 2026-04-03
### Added
- "Deploy" and "Interact" dynamic Webview UI views.
- Gas difference snapshot generation tools.
- Slither setup capabilities.

### Changed
- Converted sidebar logic to javascript bundles via Webpack for speed improvements.
- Flattened the UI design into a native VS Code style, retiring previous placeholder components.
- Integrated `ethers` v6 to properly connect and parse `forge create` ABI logic.
